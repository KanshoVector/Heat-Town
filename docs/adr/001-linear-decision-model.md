# ADR-001: 線形多目的モデル Jᵢ

**日付**: 2026-07-26（格子方針追記: 2026-07-27）  
**状態**: 採用

## 文脈

都市熱リスクを行政・市民に説明する PBL。予測精度より **Explainability First**。

## 決定

\[
J_i = w_1 d_i + w_2 (100 - C_i) + w_3 \text{WBGT}_i
\]

線形和 + 重み正規化 + 寄与分解 popup。

### 評価格子（400 点）の位置づけ

対象エリア（2km 四方）を **100m 間隔で探索的サンプリング**した PoC 用離散化（\(N \approx 20 \times 20 = 400\)）。

| 項目 | 内容 |
|------|------|
| **意図** | 分析モードで Jᵢ 空間分布を説明可能な解像度で可視化 |
| **計算量** | 前処理・export とも \(O(N)\)。クライアント再計算も \(O(N)\)（ADR-005） |
| **UX トレードオフ** | \(N \approx 400\) は「リアルタイム重みスライダー」との **Pareto 妥協点**（数千点超は事前タイル化が必要） |
| **主張しないこと** | ナイキスト・シャノン定理に基づく最小十分統計量（帯域制限・variogram 未推定） |

将来のデータ駆動間隔設計: [008-future-extensions.md](008-future-extensions.md)

### 重み \(w_k\)

`config/weights.yaml` のペルソナ別事前設定。PCA による自動決定は **採用しない**（規範的重みと PCA の目的不一致）。将来の AHP / 逆最適化: ADR-008。

## トレードオフ

| 選択 | 利点 | 欠点 |
|------|------|------|
| 線形（採用） | 寄与可視化、スライダー即時反映 | 非線形相互作用を表現不可 |
| ML / NN（不採用） | 精度向上余地 | ブラックボックス、説明困難 |
| 400 点格子（採用） | 7 分デモで説明可能、JS 即時 | 100m 未満の現象は見逃す |

## 結果

- `src/heat_town/model.py` が SSoT
- 重みプリセットは `config/weights.yaml` と MVP JS で一致
