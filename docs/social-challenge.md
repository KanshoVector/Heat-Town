# 社会課題定義

## 背景 — 都市の暑さは誰の問題か

気候変動と都市化により、日本の大都市では猛暑日・熱帯夜の頻度が増加している。高齢者を中心とした熱中症リスクが都市部で顕著である。グリーンアクセス（緑地・日陰までの距離）や移動手段の選択は、個人の属性（高齢・子ども・障害）によって大きく異なる。

本プロジェクトは **Web アプリ開発ではない**。オープンデータと説明可能な数理モデルで **「どこが、いつ、誰にとって暑さリスクが高いか」** を可視化し、行政・市民・都市計画者の意思決定を支援する **PoC** を構築する。

## 問題陈述 — 定量化可能な問い

### 主問い

> 都市空間において、**距離・アクセシビリティ・快適度・暑さ（WBGT）** を統合した多目的評価モデル \(J_i\) により、暑さリスクの高い地点を特定し、緑化・日陰・移動計画の優先順位を説明可能に提示できるか。

### 副問い

| # | 副問い | 分析での扱い |
|---|--------|--------------|
| 1 | 重み \(w_1, w_2, w_3\) を変えたとき、優先地点の順位はどれだけ変わるか | 感度分析 |
| 2 | 時間帯（WBGT 変動）で \(J_i\) はどう変化するか | 時系列比較 |
| 3 | 行政が介入しやすい施策はモデル上どこに効くか | シナリオ分析 |

## ステークホルダー

| ステークホルダー | ニーズ | PoC が提供する価値 |
|------------------|--------|-------------------|
| 市民 | 経路・外出の判断材料 | \(J_i\) ランキングと寄与説明 |
| 行政・保健所 | 重点エリア特定 | ヒートマップと重み調整 |
| 都市計画者 | 緑化優先地点 | 距離 \(d\) 項の寄与分解 |
| 授業・評価者 | PBL 成果 | 再現可能パイプラインと提言 |

## 現状の意思決定の限界

| 限界 | 対処 |
|------|------|
| 単一指標依存（気温のみ） | 多目的 \(J_i\) |
| ブラックボックス ML | Explainability First |
| データ閉鎖 | Open Data First |
| ツール先行 | 社会課題 → 分析 → PoC |

## 成功指標（KPI）

| KPI | 目標 |
|-----|------|
| 再現性 | clone → CI 緑 → 同一 GeoJSON |
| 説明可能性 | 全地点で寄与 3 項表示 |
| 分析 | 仮説 3 件以上検証 |
| 社会提言 | 施策 3 件以上・根拠付き |
| 教育適合 | 7 分発表・個人レポート |

## プロジェクトスコープ

**In Scope**: オープンデータ、\(J_i\) モデル、Leaflet PoC、GitHub 公開 doc / パイプライン

**Out of Scope**: 本番 API、NN / 予測 / FFT（[rejected-approaches.md](rejected-approaches.md)）、大規模マイクロサービス
