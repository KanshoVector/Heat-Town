# 不採用技術と将来拡張

## 設計判断の原則

MVP First · Explainability First · Reproducibility First · 車輪の再発明禁止

主役は **社会課題 → データ → 分析 → 提言**。高度な予測は PoC 目的外。

## ニューラルネット

| 不採用理由 | 将来拡張 |
|------------|----------|
| 寄与分解困難 | Phase 2: 残差 NN + SHAP |
| データ・GPU 不足 | Phase 3: NDVI + CNN |
| PBL スコープ超過 | ラベル整備後 |

## 予測モデル

| 不採用理由 | 将来拡張 |
|------------|----------|
| 問題は「未来予測」ではなく地点評価 | Open-Meteo forecast → \(J_i(t+\Delta)\) |
| RMSE 競争は提言評価とずれる | ARIMA / Prophet 局所補正 |

## フーリエ変換

| 不採用理由 | 将来拡張 |
|------------|----------|
| 短期データで周期不安定 | 夏季 3 ヶ月 WBGT 系列 |
| 社会提言に説明しにくい | 政策介入スケジュール |

## 採用モデルの優位性

| 観点 | 線形 \(J_i\) | NN / 予測 / FFT |
|------|--------------|-----------------|
| 2〜3 日完遂 | ◎ | △〜× |
| 7 分説明 | ◎ | △ |
| 行政提言 | ◎ | △ |

**結論**: 説明可能な線形 \(J_i\) を中核とし、不採用技術は Phase 2 ロードマップとして記録。
